# v1 Prompt (original, single-paragraph version)

---

Identify and assess Kenya-based manufacturing firms aligned with the Bottom-Up Economic Transformation Agenda (BETA), focusing on value-addition activities across BETA priority value chains (dairy, edible oils, tea, leather, rice, cotton, and blue economy) and the Agricultural Transformation and Inclusive Growth pillar. For each firm, evaluate BETA alignment using the 7-criterion framework (pillar/value-chain fit, value addition, grassroots/inclusion linkages, jobs and local employment, market access and foreign exchange, public programme participation, and formality/credibility), verify entity status using public sources, assess internationalization signals where evidence exists, and produce a scored shortlist of 5–10 firms with evidence-backed scorecards, confidence assessments, and strategic implications — all using publicly available data sources.
